Downward Right-Angled Triangle (ELI5)

This program prints a triangle of stars. It starts with a wide row and makes each next row one star shorter.

Imagine three rows of stars

The first row gets 3 stars, the next gets 2, and the last gets 1.

* * *
* *
*

Two loop helpers

Think of the loops as two helpers: the outer loop picks how many stars a row should have, and the inner loop puts those stars on that row.

1. Choose the starting row size

let n = 3;

n says the first row starts with 3 stars.

2. Pick how many stars this row gets

for (let i = n; i >= 1; i--) {

The outer loop starts i at 3. After each row, i-- takes away one. The row sizes are 3, then 2, then 1. When i becomes 0, the condition i >= 1 is false, so the loop stops.

3. Put stars on that row

    for (let j = 1; j <= i; j++) {
        process.stdout.write("* ");
    }

Every row starts counting again at j = 1. The inner loop writes a star while j is less than or equal to i, so it writes exactly as many stars as the current value of i.

Why use process.stdout.write? It writes the stars without moving to the next line, so they stay together on the same row.

4. Start the next row

    console.log("");

After all the stars for a row are written, this moves the output to the next line.

Follow the loop

In short

  • i decides how many stars the current row gets.
  • j counts the stars on that row.
  • i-- makes each new row shorter.
  • console.log("") moves to the next row.
