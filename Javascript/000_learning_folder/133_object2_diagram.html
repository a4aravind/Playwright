Why does a.status become "fail"?

The key is that a and b point to the same object. Think of one toy box with two labels attached to it. 

let a = { status: "pass" };
let b = a;  // Copy the reference
b.status = "fail";
console.log(a.status);

Step-by-step

  1. Create the object
    let a = { status: "pass" }; creates one object. Its status property starts as "pass", and a refers to that object.
    a → { status: "pass" }
  2. Copy the reference, not the object
    let b = a; makes b refer to the very same object. It does not create another object.
  3. Change the shared object's property
    b.status = "fail"; follows b to the object and changes its status. Since a points to that same object, the object's status is now "fail" for both names.
    a → { status: "fail" }
    b → { status: "fail" } (both arrows lead to the same object)
  4. Read the property through a
    console.log(a.status); follows a to that object and reads its current status: "fail".

Important: a itself was not changed to point somewhere else. The object it points to was changed through b.
